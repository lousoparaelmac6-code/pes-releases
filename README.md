# PES — Descargas oficiales

Este repositorio publica los instaladores oficiales de PES para Android y Windows. Las versiones se publican por separado con etiquetas `apk-v*` y `desktop-v*`. Los manifiestos de cada release incluyen la versión, la URL directa y el SHA-256 del instalador.

Descargá únicamente los archivos adjuntos a las releases oficiales.
